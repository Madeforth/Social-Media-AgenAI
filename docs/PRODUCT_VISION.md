# Product Vision

## Vision

Create an AI-native social media operating system where a brand can be defined once and continuously expressed through strategy, visuals and copy without losing consistency.

## Product Positioning

Not another scheduler. Not another template editor. Not merely a chatbot.

Apex Social AI combines:

- brand memory,
- strategic planning,
- creative direction,
- visual generation,
- copywriting,
- review,
- scheduling,
- publishing,
- and later performance learning.

## North-Star Workflow

`Brand Brain → Strategy → Creative Concept → Design + Copy → QA → Approval → Schedule → Publish → Measure → Learn`

## V1 Success

The user can create one brand, upload/define its brand system, generate several high-quality posts, approve one from mobile or web, schedule it and see it publish automatically to Instagram.
