# Product Context

## Product Experience

The product should feel like a creative operating system rather than an admin dashboard. Large visual previews, strong hierarchy, minimal controls and fast approval are more important than dense enterprise tables.

## Key Mental Model

The AI is a creative director + strategist + copywriter + designer. It is not merely a prompt box.

## Content Philosophy

The AI decides the best format based on strategy. UI-heavy product posts are only one format among many.

Content families include:

- Product feature
- Brand awareness
- Lifestyle / rider emotion
- Community
- Data story
- Education
- Achievement
- Teaser / launch
- Seasonal/event
- Manifesto/typographic

## Approval Philosophy

V1 should default to human approval. The owner can later opt into greater autonomy.

## Synchronization

All non-image content, versions, statuses, schedules and metadata are stored centrally in Supabase and must be available everywhere.

## Image Handling

Generated images and uploaded assets are stored in Supabase Storage. PostgreSQL stores only references/paths/metadata.
