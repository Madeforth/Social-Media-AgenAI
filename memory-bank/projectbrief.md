# Project Brief

## Project

Apex Social AI

## Problem

Managing social media content currently requires separate tools for strategy, copywriting, visual design, approval, scheduling and publishing. The goal is to centralize this into a single AI-first system that works consistently across web, iOS and Android.

## Primary User

A hands-on brand owner / social media specialist / designer who wants high-quality creative output without maintaining servers or stitching many SaaS subscriptions together.

## First Real Brand

Apex Flow — a premium motorcycle-tech product.

## Main User Outcome

The user should be able to say “prepare this week’s posts” and receive brand-appropriate concepts, designs and captions ready for approval and scheduling.

## V1 Scope

- Authentication
- Multi-brand-ready brand model
- Brand Brain
- Asset Library
- Gemini strategy/copy/design generation
- Content history
- Human approval and revision
- Content calendar
- Instagram scheduling/publishing
- Web/mobile synchronization
- Push notification for items requiring approval

## Out of Scope for Early V1

- Team permissions beyond basic ownership
- Deep analytics automation
- Multi-platform publishing beyond Instagram
- Full autonomous no-approval posting
- Self-hosted infrastructure
- Full inbox/DM automation
